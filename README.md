# 🏦 Bank Management System

A console-based **Bank Management System** developed using **Python and MySQL**.  
The application allows users to create bank accounts and perform basic banking operations such as viewing accounts, depositing money, withdrawing money, and checking account balances.

---

## 📌 Project Overview

The Bank Management System demonstrates how a Python application can interact with a relational database using **MySQL Connector/Python**.

The project follows a modular structure where:

- `main.py` handles application startup.
- `menu.py` manages the user interface and menu navigation.
- `account_operations.py` contains the core banking logic.
- `db_config.py` manages the MySQL database connection.

---

## ✨ Features

- 🧾 Create a new bank account
- 👥 View all accounts
- 💰 Deposit money
- 💸 Withdraw money
- 💳 Check account balance
- 🗄️ MySQL database integration
- 🔄 CRUD-based database operations
- 🧩 Modular Python project structure
- ⚠️ Basic validation for account and withdrawal operations
